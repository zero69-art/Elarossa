# Accessibility audits (Elarossa)

Automated checks use **axe-core** via Playwright (`@axe-core/playwright`).

## Standards

- Tags: `wcag2a`, `wcag2aa`, `wcag21a`, `wcag21aa`
- **Fail** the suite on impact: `critical` or `serious`
- **Warn** only on `moderate` / `minor`

## Commands

```bash
npm install   # installs @axe-core/playwright
npm run build && npm run start   # in another terminal if needed
npm run test:a11y

# Against production
PLAYWRIGHT_BASE_URL=https://elarossa.vercel.app npm run test:a11y
```

## CI

QA workflow runs `npx playwright test --project=a11y` after smoke. Failures fail the job (not continue-on-error).

## Fixing issues

1. Read the violation `id` + help URL in the test output
2. Prefer semantic HTML (`button`, labels, headings order)
3. Ensure focus styles and contrast on text CTAs (`.cta-ink` already forces white on ink)
